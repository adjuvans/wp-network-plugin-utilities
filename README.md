# Network Plugin Utilities (MU)

Affiche dans le back-office réseau un tableau récapitulatif de tous les sites de la plateforme multisite. Pour chaque site, l’outil liste :

* les utilisateurs et leurs rôles,
* les contenus publiés (articles, pages et custom post types),
* les taxonomies et le nombre de termes associés,
* les plugins activés localement (hors plugins réseau).

Permet aux administrateurs réseau d’auditer rapidement l’état et la configuration de chaque site.
